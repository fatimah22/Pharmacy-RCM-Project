*Hospital Project – Pharmacy Revenue Cycle Management*
**Project Summary**
This project is a hospital-focused analytics portfolio project centered on Pharmacy Revenue Cycle Management (RCM). The goal is to build a strong end-to-end analytics case that connects clinical, operational, financial, and quality concepts where relevant, with a current focus on pharmacy workflows, revenue cycle logic, KPI design, SQL transformation logic, and dashboard planning.

Project Objectives
Build a realistic healthcare analytics project suitable for a professional portfolio.

Organize hospital data into a structured medallion architecture.

Clean and standardize source data using SQL Server.

Create analytics-ready tables for KPI calculation and dashboard reporting.

Translate raw hospital data into business questions, insights, and reporting use cases.

Current Focus Areas
Pharmacy analytics

Revenue cycle management (RCM)

Data quality checks

Bronze, Silver, and Gold layer design

KPI logic and metric definitions

Dashboard planning for Power BI

Business Questions
The project is being shaped to answer questions such as:

How is pharmacy activity captured across the hospital data model?

Which data elements support operational and financial pharmacy KPIs?

What data quality issues affect reporting reliability?

How should raw source data be transformed into clean analytical tables?

Which Gold-layer outputs should feed the final dashboard?

Technical Stack
SQL Server

CSV source files

Medallion architecture (Bronze / Silver / Gold)

Power BI for dashboard design

GitHub for project structure and version control

Project Deliverables
SQL scripts for table creation and loading

Data quality checks for selected source tables

Silver-layer cleaning and standardization logic

Gold-layer analytical views

KPI planning documents

Dashboard planning documentation

GitHub-ready project structure

Expected Outcome
The expected outcome is a clear, well-documented healthcare analytics portfolio project that demonstrates data modeling, data quality management, SQL transformation logic, and dashboard planning in a hospital context.
